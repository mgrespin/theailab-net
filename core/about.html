What This Course Is

IPHS 400 is a hands-on study of AI software engineering (AI-SWE) as it stands in late 2026: configuring, extending, and orchestrating AI coding agents such as Claude Code through a professional software development lifecycle. You build the competency through four stacked mini-projects — development environment, agent configuration and custom Skills, agent harness and hooks, and a spec-driven SDLC capstone — and then apply the whole toolchain to an original interdisciplinary research project. Running alongside the technical work is an ongoing discussion of the labor, ethical, and epistemic stakes of agentic systems in knowledge work.

See the Syllabus for the full course description and the nine learning outcomes, and Assignments for the mini-project and final-project details.
